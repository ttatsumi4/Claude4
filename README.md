# メルカリ出品用 ISBN検索ツール

メルカリで本を出品する際に、ISBNから書籍情報を簡単に検索できるツールです。

## 🌟 機能

- ISBN番号（10桁または13桁）から書籍情報を自動取得
- 書籍のタイトル、著者、出版社、出版日などの詳細情報を表示
- 書籍の表紙画像を表示
- タイトルと著者名をワンクリックでコピー
- モバイル対応のレスポンシブデザイン

## 🚀 使い方

1. ISBN番号を入力（ハイフンなしで10桁または13桁）
2. 「検索」ボタンをクリック
3. 書籍情報が表示されます
4. 「タイトルをコピー」ボタンでメルカリの出品タイトルに使用できます

## 📱 デモ

GitHub Pagesで公開する場合:
1. このリポジトリの Settings > Pages に移動
2. Source を `main` ブランチに設定
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセス可能

## 🔧 技術仕様

- 純粋なHTML/CSS/JavaScript（外部依存なし）
- Google Books API を使用して書籍情報を取得
- フォールバックとして openBD（日本の書籍情報API）を使用
- 静的ファイルなのでGitHub Pagesで簡単にホスティング可能

## 📝 API について

このツールは以下の無料APIを使用しています：

1. **Google Books API** - グローバルな書籍データベース
2. **openBD** - 日本の書籍データベース（Google Booksで見つからない場合）

## 💡 ヒント

- ISBNはバーコードの下に印刷されている13桁または10桁の数字です
- ハイフンは自動的に削除されるので、入力してもOKです
- Enterキーでも検索できます
